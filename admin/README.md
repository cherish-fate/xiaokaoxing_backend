# 校考星管理端

Vue 3 + Vite 管理端，默认开发地址：http://127.0.0.1:5173/

## 使用方式

```bash
cd admin
npm install
npm run dev
```

开发服务器已配置 `/api` 代理到 `http://127.0.0.1:3000`，先启动后端服务再登录。

## 默认管理员

- 邮箱：`admin@xiaokaoxing.com`
- 密码：`admin123`

全新数据库由 `sql/init.sql` 创建；已有数据库执行 `sql/migration_admin.sql` 后即可获得管理员字段和默认管理员账号。

## 功能

- 统计看板：用户、资源、考点、小队、打卡等核心数据
- 用户管理：搜索、禁用/启用、设置管理员、重置密码
- 资源审核：通过/拒绝、设置热门、删除
- 考点审核：通过/拒绝、删除
- 小队管理：解散小队
